Employee Attrition Analysis Using Python

Project Overview

Employee Attrition Analysis is a data analysis project that investigates the factors associated with employees leaving an organization.

The project uses Python to clean, analyze and visualize employee data to identify patterns and provide insights that may help organizations improve employee retention.

Project Objective

Analyze employee attrition patterns.

Identify factors associated with employee turnover.

Compare attrition rates across different employee groups.

Create visualizations to understand employee behavior.

Provide data-driven recommendations for employee retention.

Dataset Information

Dataset: IBM HR Analytics Employee Attrition Dataset

Total Records: 1,470 employees

Total Columns: 35

Employees who stayed: 1,233

Employees who left: 237
